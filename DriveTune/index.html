Configuração inicial

Para entrar com sua conta do YouTube, o site precisa de um Client ID OAuth do Google. É gratuito e feito uma única vez.

  1. Acesse console.cloud.google.com e crie um projeto.
  2. Em APIs e serviços → Biblioteca, ative a YouTube Data API v3.
  3. Em Tela de permissão OAuth, escolha Externo e adicione seu e-mail em Usuários de teste.
  4. Em Credenciais → Criar credenciais → ID do cliente OAuth, tipo Aplicativo da Web. Em Origens JavaScript autorizadas, adicione:
  5. Copie o Client ID gerado e cole abaixo.

    Configurar o GPS

    O mapa usa a Google Maps Platform e precisa de uma chave de API do seu projeto no Google Cloud (com faturamento ativo; o uso pessoal fica dentro da cota gratuita).

    1. No Console, ative: Maps JavaScript API, Places API (New) e Routes API.
    2. Em Credenciais → Criar credenciais → Chave de API.
    3. Restrinja a chave a sites: e às 3 APIs acima.
