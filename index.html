01 · sobre

Tecnologia a serviço do negócio

Sou Administrador de Banco de Dados SQL Server na Solfarma, onde entrei em 2015 como programador júnior e cresci até analista sênior, conduzindo as sprints do time como Scrum Master, antes de assumir a área de dados.

No dia a dia analiso e otimizo consultas T-SQL, investigo falhas de sistema e automatizo rotinas. Foi desse trabalho que nasceu o GS300TI, ferramenta que criei para automatizar o deploy de bancos de dados e o backup estrutural.

Antes da TI, trabalhei sete anos como mecânico. Talvez venha daí a mania de abrir o capô para entender como as coisas funcionam por dentro, e projetos pessoais como o DriveTunes.

  • Performance em SQL Server

    Tuning de consultas T-SQL, índices e análise de falhas em produção.

  • Automação

    Rotinas, deploy de banco e backup estrutural sem trabalho manual.

  • Desenvolvimento

    Sistemas em C# e .NET, app Android nativo e portal web em Angular.
